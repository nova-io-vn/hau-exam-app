# Mobile Design System

Mobile dùng cùng nhận diện với HAU Exam Web:

- Primary: `#134D8B`
- Primary hover: `#0F4177`
- Primary active: `#0B3768`
- Primary soft: `#EDF5FC`
- Background: `#F4F7FA`
- Surface: `#FFFFFF`
- Primary text: `#172033`
- Secondary text: `#667085`
- Border: `#D9E2EC`
- Success: `#16835D`
- Warning: `#D97706`
- Danger: `#D92D20` (chỉ dùng cho lỗi/hành động nguy hiểm)

Typography ưu tiên `Be Vietnam Pro`, sau đó dùng font hệ thống tương thích React Native.

Buttons/inputs: 8-12px radius.
Cards: 12-16px.
Sheets/modals: 16-20px.
Badge: pill.

Ưu tiên:
- safe area
- keyboard-safe form
- touch target đủ lớn
- FlatList cho danh sách lớn
- bottom sheet cho filter/action phụ
- skeleton/loading/error/empty states

Không copy desktop table nguyên xi xuống mobile.
